| 구성 요소                 | 한 줄 정의                                                              |
| --------------------- | ------------------------------------------------------------------- |
| **Servlet**           | **HTTP 요청을 받아 처리하고 HTTP 응답을 만드는 자바 프로그램**                           |
| **Tomcat**            | **HTTP 요청을 받아 적절한 서블릿을 실행하고 HTTP 응답을 클라이언트에게 전달하는 웹 서버이자 서블릿 컨테이너** |
| **DispatcherServlet** | **Spring MVC의 모든 요청을 받아 적절한 Controller에 전달하는 서블릿**                  |
|                       |                                                                     |
|                       |                                                                     |
